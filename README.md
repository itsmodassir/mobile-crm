# Mobile CRM PWA

**[Open Live App 📱](https://mobile-crm.netlify.app)**

A local-first, premium Mobile CRM application built with React, TailwindCSS, and PWA capabilities.

## Features

- **Offline Support**: Works without internet connection (PWA).
- **Lead Managment**: CRUD (Create, Read, Update, Delete) leads.
- **Call Disposition**: Automated workflow to tag calls (Hot/Warm/Cold) after dialing.
- **Import/Export**: JSON data portability.
- **Stats Dashboard**: Visual breakdown of your pipeline.
- **Privacy First**: All data is stored locally in your browser/device.

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Locally**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

## Installation (PWA)
- **Mobile**: Open in browser > Share > Add to Home Screen.
- **Desktop**: Install via the address bar icon in Chrome/Edge.
